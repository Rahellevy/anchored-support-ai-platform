Red-flag detection

Every patient message is checked against the configured rules. This page shows what was flagged, why it was flagged, and how the different detection methods compare.

This is not a guaranteed clinical safety system. It can miss concerning messages (false negatives) and flag harmless ones (false positives), especially when it has to interpret natural language. A therapist reviews every flag, and no flag does not mean a message is safe.

Recommended approach: hybrid

Subject to sponsor decision

  • Keyword and pattern checks always run and are never overruled.
  • A model can only add flags. It cannot remove or downgrade one.
  • Severity always comes from the rule, never from the model.
  • If a check fails, the others still decide and the result is marked incomplete.

Known limits of rule-based checks

Shown on the Try a message tab

  • Negation: "I don't have thoughts of hurting myself" still matches.
  • Slang and paraphrase: "nobody would notice if I disappeared" matches nothing.
  • Time: "I felt hopeless last year" matches as if it were now.
